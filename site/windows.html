The desktop dictation flow

Built for the desktop

Focused, quiet, and out of the way

A global shortcut

Alt+Q starts and stops dictation in any ordinary text field. Change the shortcut to whatever fits.

Types into the focused window

Unicode SendInput writes where your cursor is. If Windows isolation blocks it, the transcript falls back to your clipboard.

Refuses password fields

Detected via Windows UI Automation before recording and again before insertion — never reads or writes a secret.

Keys encrypted with DPAPI

Each provider's key is isolated and protected for the current Windows user. Quill runs unelevated by design.

Fail-soft cleanup

Optional AI cleanup tidies filler and punctuation, guarded so a bad pass always falls back to your raw words.

Same privacy model

No account, no backend for your data. History is local with time-based retention; private mode keeps nothing.

Dictate on the desktop

Quill for Windows ships as a self-contained installer — no separate runtime required.
