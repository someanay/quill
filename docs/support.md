# Quill support

For setup help, privacy questions and licensing enquiries, email **[quillapp@agentmail.to](mailto:quillapp@agentmail.to)**.

## Setup

1. Install the official [Android preview](https://github.com/someanay/quill/releases/tag/android-v1.0.23).
2. Open Quill and follow the Groq key instructions. Other supported provider configurations are in Settings.
3. Enable microphone, display-over-other-apps and accessibility access when prompted.
4. On phones with aggressive battery management, allow Quill to run in the background through the manufacturer's settings.

The app is free; provider API usage may have charges or limits. A valid key does not guarantee quota or access to every model.

See [dictation errors and recovery](dictation-errors.md) for the permission, recording, connection and provider messages shown by Quill.

## Report a problem

Use the [bug report form](https://github.com/someanay/quill/issues/new?template=bug_report.yml). Include the app version, phone model, Android version, provider name and steps to reproduce. Say what you expected and what happened.

Public issues are visible to everyone. Do not post API keys, real transcripts, recordings, names, contacts or private screenshots. You can demonstrate a problem using invented text.

## Privacy and security

Email the address above for sensitive concerns. Follow the [security reporting guidance](../SECURITY.md). Never send an API key; rotate a key with its provider if it has been exposed.

Quill has no user account or hosted transcript store. Clear local data through Quill Settings or Android Settings; contact your provider about data processed by that provider.

## Preview limits

The current package is com.quill.quill. It installs separately from the former package, so keys and permission grants need to be set up again.

The [release-readiness page](play-readiness.md) distinguishes automated verification from physical-device checks still pending. Provider responses, third-party text fields and phone power management can affect results.
