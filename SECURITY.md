# Security reporting

Report a suspected security or privacy issue privately to **[quillapp@agentmail.to](mailto:quillapp@agentmail.to)**.

Do not open a public issue with exploit details, provider keys, real audio, transcripts or personal information. Include the Quill version, phone/Android version, a description of the issue and reproduction steps using invented data.

We will review reports and coordinate follow-up by email. This project does not promise a paid bounty or a fixed response deadline.

## Current scope

The current downloadable build is Android preview 1.0.22, package com.quill.quill. Physical-device and production-release checks remain open as described in [release readiness](docs/play-readiness.md). Older builds and experimental ports are not part of that preview's support commitment.

If a provider key has been exposed, revoke or rotate it through the provider. Quill cannot revoke third-party credentials.

For ordinary bugs, use the [bug report form](https://github.com/someanay/quill/issues/new?template=bug_report.yml). For data-handling information, read the [privacy policy](docs/privacy-policy.md).
